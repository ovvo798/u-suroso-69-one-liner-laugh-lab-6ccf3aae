## What it does

`main.py` (Python 3.13, standard library only) writes one short funny
line — the excuse a robot vacuum gives after eating a sock — to
`/output/entry.txt`.

> I didn't eat your sock — I adopted it. It lives under the couch now,
> and frankly, it's happier there than it ever was in your drawer.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no secrets, no input: the line is baked into the program.
